# AI-Powered Brain Disease Classifier

## Overview

This project is a deep learning-based application designed to detect neurological diseases such as Alzheimer’s, Brain Tumor, and Stroke from MRI scan images. It aims to assist in early diagnosis using AI-driven predictions.

## Problem Statement

Manual analysis of MRI scans requires expertise and can be time-consuming. Delays or errors in diagnosis can impact patient outcomes.

## Solution

A deep learning model was developed to classify MRI images into different disease categories. The system provides real-time predictions through a simple interface.

## Tech Stack

* Python
* TensorFlow / Keras
* OpenCV
* Flask / FastAPI
* HTML, CSS, JavaScript

## Features

* Upload MRI images for analysis
* Real-time disease prediction
* Multi-class classification
* User-friendly interface

## Results

The model achieves strong performance on test datasets and is capable of identifying multiple neurological conditions efficiently.
